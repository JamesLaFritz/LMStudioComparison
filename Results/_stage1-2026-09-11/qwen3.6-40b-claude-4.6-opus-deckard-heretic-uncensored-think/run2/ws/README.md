# Space Invaders — AAA Retro-Futurism Edition

## Setup & Run

```bash
npm install
npm run dev
```

Open http://localhost:5173/Space_Invaders/index.html in browser.

## Controls

- **WASD / Arrow Keys** — Move ship left/right, fire with spacebar
- **Gamepad** — Left stick to move, Button 0 to fire

## Features

- Procedural asset generation (no external files)
- Object pooling for projectiles and particles
- Camera shake, hit-stop frame freeze, motion trails, shockwave rings
- Neon glow emitters via UnrealBloomPass post-processing
- Glassmorphism UI overlay with neon accents
- Dual input: keyboard + gamepad API
